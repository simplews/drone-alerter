# IF Reactive Drone Early Alert System

> **Автоматизована система раннього попередження про загрозу реактивних БпЛА для Івано-Франківська.**
> Створено на основі моніторингу відкритих каналів у коридорі Поділля → Тернопільщина → Франківщина.

---

## 🎯 Основна мета

Забезпечити мешканців та служби міста Івано-Франківськ випереджальним сповіщенням (ETA) про наближення швидкісних («реактивна герань» / Shahed-238, 450–600 км/год) безпілотників із часом попередження $\ge 7$ хвилин до офіційної тривоги по району та $\ge 5$ хвилин до ручних повідомлень у місцевих каналах.

---

## 🏗 Архітектура системи

Система побудована за принципами **Clean Architecture**:

- **Core Engine (`src/engine/`)**:
  - `tracker.py`: Відстеження цілей, дедуплікація спостережень між каналами ($\Delta t \le 6$ хв), безпечне асиметричне зняття загрози (правило F7), захист від спаму сповіщеннями (правило F8).
  - `eta.py`: Гібридний розрахунок ETA ($d / v \pm \text{lag}$) та градація небезпеки (Рівні 1, 2, 3a, 3b).
  - `simulation.py`: Оцінка критеріїв готовності Go/No-Go (розділ 7 PRD).
  - `shadow_runner.py`: CLI-раннер для симуляції історичних прольотів та аналізу релізу.
- **NLP Normalizer (`src/nlp/`)**:
  - `normalizer.py`: Контекстне наслідування реактивного типу БпЛА у ланцюжку постів, відмінювання населених пунктів, класифікація дій (`DOWNED`, `LOST`, `DIVERTED`).
- **Continuous Learning & Reference Repository (`src/learning/`)**:
  - `reference.py`: Версійовані незмінні довідники (`vNNNN.json`) із миттєвим перемиканням активної версії через покажчик `ACTIVE`.
  - `calibration.py`: Асиметричне калібрування ETA та баєсівська ймовірність відхилення.
  - `aliases.py`: Автоматичний видобуток кандидатів у нові назви з текстів моніторингів із верифікацією людиною.
  - `cli.py`: Консольний інтерфейс оператора для розмітки результатів (`label`), перегляду черги (`aliases`) та запуску перенавчання (`retrain`).
- **Telegram Adapters (`src/telegram/`)**:
  - `listener.py`: Telethon MTProto клієнт з heartbeat та автоматичним сповіщенням про розрив зв'язку.
  - `bot.py`: Aiogram 3 бот сповіщень із підтримкою DND-налаштувань користувача та приватності (`/stop`).
  - `generate_session.py`: Генератор безфайлової сесії `TELETHON_STRING_SESSION`.
- **Healthcheck & Monitoring API (`src/api/`)**:
  - `server.py`: FastAPI ендпоінти `/health` та `/targets`.

Двигун не прив’язаний до одного міста: усі дані коридору, ключові слова й тексти бота лежать у профілі `data/profiles/<місто>.json`. Інструкція: [docs/ADAPTING.md](docs/ADAPTING.md) (англійською).

## 🚀 Швидкий старт

### 1. Встановлення залежностей локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Ініціалізація довідника

```bash
python -m src.learning.cli seed
```

### 3. Запуск тестів та перевірки якості коду

```bash
pytest
ruff check .
```

### 4. Запуск сервісу

Створіть файл `.env` на основі `.env.example`:
```bash
cp .env.example .env
# заповніть токени в .env
python -m src.main
```

## 🛡 Безпекові принципи

1. **Жодної інформації про ППО:** Система ніколи не публікує координати, локації збиття або роботу засобів протиповітряної оборони.
2. **Асиметричне закриття цілі (F7):** Система ніколи не транслює команди «Відбій» чи «Ціль знищено». Замість цього видається застереження: *«За повідомленнями каналів, ціль, імовірно, уражена. Залишайтеся в укриттях до офіційного відбою ОВА/ПС»*.
3. **Обмежений термін зберігання:** Сирі тексти постів видаляються автоматично через 14 днів (TTL).

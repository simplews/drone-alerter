# Проєкти текстів та налаштувань Telegram

Цей документ містить підготовлені тексти для оновлення профілю бота в BotFather та закріпленого повідомлення в закритій адміністративній групі.

---

## 1. Short Description (BotFather `/shortdesc`)
> Ліміт Telegram: до 120 символів. Відображається перед початком діалогу з ботом та у списку посилань.

```text
Раннє сповіщення про загрозу БпЛА для Франківська. Не замінює офіційну тривогу: під час сирени негайно в укриття!
```
*(довжина: 113 символів)*

---

## 2. Description (BotFather `/setdescription`)
> Ліміт Telegram: до 512 символів. Відображається на головному екрані нового чату («Що вміє цей бот?»).

```text
Волонтерський бот раннього оповіщення про загрозу ударних БпЛА (реактивних та Шахедів) для Івано-Франківська й області.

Що робить бот:
• Транслює офіційні повітряні тривоги та відбої.
• Аналізує моніторингові канали й попереджає про рух дронів транзитним коридором із розрахунковим вікном підльоту (ETA).

⚠️ Головне правило: бот не є офіційним джерелом. Якщо оголошено тривогу — негайно прямуйте в укриття, навіть якщо сповіщень від бота немає.
```
*(довжина: 446 символів)*

---

## 3. Закріплене повідомлення для закритої групи розробки / адміністрування
> Для чату `FEEDBACK_CHAT_ID`, куди надходять сповіщення або звернення від користувачів.

```text
📌 **Памʼятка для команди та адмінів чату**

Цей чат використовується для моніторингу роботи сервісу та технічної підтримки користувачів бота.

💬 **Робота зі зверненнями (фідбек):**
• Звернення користувачів надходять із позначкою «Звернення #...».
• Щоб відповісти користувачеві, зробіть звичайний **Reply** на повідомлення зі зверненням. Бот автоматично надішле копію вашої відповіді безпосередньо користувачеві від свого імені.
• Особистий акаунт розробника/адміна користувачеві **не показується**.
• Відповідати на звернення мають право лише облікові записи, зазначені в `FEEDBACK_ADMIN_IDS`.

🚦 **Кольорове маркування сповіщень:**
• 🔴 **Рівень 3 (підліт / над містом):** пряма загроза, термінове гучне сповіщення.
• 🟠 **Рівень 2 (наближення):** ціль на підходах до найближчих рубежів, гучне сповіщення.
• 🟡 **Рівень 1 (потенційна загроза):** дальній рубіж (вхід у транзитний коридор), надходить без звуку.
• ⚪️ **Службові / статус цілей:** інформування про ймовірне збиття, втрату локації цілі або закінчення часу очікування (таймаут). Не є відбоєм небезпеки!

🛠 **Дії при технічному збої:**
1. Перевірте статус сервісу на сервері (`systemctl status drone-alert` або `docker compose ps`).
2. Ознайомтеся з логами: `journalctl -u drone-alert -n 100 -f`.
3. У разі втрати звʼязку з Telegram Telethon/Bot API перезапустіть службу (`systemctl restart drone-alert`).
4. Якщо виявлено невідповідність розпізнавання пунктів або аномалії в ETA — створіть issue / завдання на донавчання моделі без редагування захищених reference-файлів.
```
